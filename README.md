## About
This repository contains my data engineering projects built with **Databricks** and **PySpark**.
Each project works with real datasets to clean, transform and analyze data, and to answer business questions.

## Project Levels

### 🟢 Beginner
Projects that cover the core PySpark basics: reading data, selecting columns, filtering rows, sorting, creating new columns and handling missing values.

### 🟡 Intermediate
Projects that combine and summarize data using aggregations, joins, conditional logic, date functions and window functions.

### 🔴 Advanced
Projects that focus on building complete data pipelines, using the Medallion Architecture (Bronze, Silver, Gold), Delta Lake and performance optimization.
